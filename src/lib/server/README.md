# NAFAS | نَفَس — البنية التحتية للخادم والإنتاج (Server & Production Spec)

> **حالة النظام الحالية:** وضع العرض التجريبي (`demo_simulator`).  
> **الغرض من هذا التوثيق:** بيان متطلبات الربط الخادمي الحقيقي والمخططات وسياسات الأمان والبيانات الناقصة للتشغيل الإنتاجي الفعلي، دون افتراض وجود بنية تحتية لم يتم ربطها بعد.

---

## 1. المتغيرات البيئية المطلوبة للإنتاج (Environment Variables Checklist)

للانتقال من وضع العرض التجريبي إلى الإنتاج الفعلي، يجب تهيئة المتغيرات التالية على خادم الاستضافة (مثل Vercel, Railway, أو خادم حكومي محلي):

| المتغير | الوصف | مثال لقيمة قياسية | الحالة الحالية |
| :--- | :--- | :--- | :--- |
| `DATABASE_URL` | سلسلة اتصال قاعدة بيانات PostgreSQL 15+ مع إضافة PostGIS | `postgresql://nafas_admin:***@db.nafas.iq:5432/nafas_prod?sslmode=require` | ❌ غير مهيأ (معروض في وضع Demo) |
| `NEXT_PUBLIC_API_URL` | مسار الواجهة البرمجية المعتمدة للإنتاج | `https://api.nafas.iq/v1` | ❌ غير مهيأ (يعمل محلياً) |
| `AUTH_SECRET` | مفتاح التوقيع الرقمي للرموز (JWT / Sessions) | `openssl rand -hex 64` | ❌ غير مهيأ |
| `SMS_GATEWAY_API_KEY` | مفتاح مزود الرسائل القصيرة OTP (زين العراق / آسيا سيل) | `sms_live_key_***` | ❌ غير مهيأ |
| `S3_STORAGE_BUCKET` | حاوية تخزين الصور والأدلة البيئية الموثقة مع التشفير | `nafas-evidence-encrypted` | ❌ غير مهيأ |

> **تنبيه أمني:** لم يتم حقن أو توليد أي مفاتيح وهمية أو أسرار حقيقية في المستودع التزاماً بسياسة الأمان وعدم توليد اشتراكات مدفوعة أو حسابات خدمة من تلقاء النفس.

## 2. ترحيل قاعدة البيانات (Database Migrations)

ملف المخطط الكامل متوفر تحت المسار:
`src/lib/server/schema.sql`

يتضمن:
1. **جداول البيانات:** `users`, `reports`, `report_audit_logs`, `campaigns`, `campaign_registrations`, `certificates`.
2. **قيود السلامة الجغرافية:** فحص حقيقي للإحداثيات ضمن حدود العراق (`lat 28.5–38.5`, `lng 38.0–49.5`) وفهرس مكاني `GIST(geom)`.
3. **منع تكرار التسجيل:** قيد فريد `UNIQUE(campaign_id, user_id)` على جدول `campaign_registrations`.
4. **سياسات الأمان على مستوى الصف (RLS):**
   - حصر اعتماد البلاغات وتغيير حالتها بالمشرفين والمدراء (`moderator`, `admin`).
   - حصر إصدار الشهادات الرقمية المعتمدة بالمنسقين والمدراء (`organizer`, `admin`).
   - عزل تسجيلات المتطوعين بحيث لا يرى المستخدم إلا تسجيلاته الخاصة.

## 3. محاكي المعاينة vs التشغيل الإنتاجي (Demo vs Production Architecture)

| الميزة | وضع المعاينة الحالي (Demo Simulator) | وضع الإنتاج (Production Backend) |
| :--- | :--- | :--- |
| **تخزين البيانات** | حالة الذاكرة المؤقتة للعميل (`useState` في React) | قاعدة بيانات PostgreSQL موحدة موزعة |
| **تبديل الأدوار في الرأس** | محاكاة تفاعلية لتجربة تجربة المستخدم للمراجعين | جلسات مشفرة مع تحقق من الهوية الثنائية (OTP) |
| **إصدار الشهادات** | موسومة بـ `isDemoCertificate: true` ووسم مائي تجريبي | توقيع رقمي رسمي من الخادم مع بصمة ختم وطنية |
| **التحقق من الإحداثيات** | تحقق هندسي محلي بنظام تقاطع المضلعات (Ray-Casting) | استعلامات PostGIS الرسمية مع تدقيق حدود المحافظات |
