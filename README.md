## 🌾 Overview
**NAFAS (نَفَس)** is an authentic, civic-scale environmental ecosystem engineered specifically for Iraq. It bridges the gap between grassroots citizens noticing ecological degradation, passionate volunteer mobilization, municipal coordination, and verified restoration.

NAFAS rejects generic environmental green templates and superficial NGO tropes. Rooted in the rich cultural, geological, and hydrological history of the Tigris (*Dijlah*) and Euphrates (*Furat*), NAFAS adopts the warm mineral tones of Mesopotamian fired clay, river mist, and dawn skies over the southern marshes (*Ahwar*).

---

## 🏛️ Core Features

- **Geospatial Reporting**: Precision incident logging covering Iraq's 18 governorates with automated hazard analysis (immediate warning triggers for hazardous/chemical/electrical debris).
- **Audit-Logged Report Lifecycle**: Full state transitions (`Submitted` → `Under Review` → `Verified` → `In Progress` → `Resolved` / `Duplicate` / `Rejected`) with actor and timestamp attribution.
- **Before & After Remediation Evidence**: Interactive, keyboard-accessible slider proving tangible remediation with verified badges and date stamps.
- **Campaign & Volunteer Mobilization**: Complete organizer and volunteer flows, real-time quota tracking, gear requisites, and attendance verification.
- **Volunteer Passport (جواز نَفَس)**: Personal civic ledger tracking verified cleanup hours, saplings planted, and community impact.
- **Verifiable Digital Certificates**: Cryptographically formatted unique IDs (`NFS-IQ-2026-XXXXX`) paired with live QR code lookup.
- **Regional Iraqi Planting Guide**: Climate-specific recommendations across all 18 governorates prioritizing native drought-resilient flora (Date Palm, Sidr, Olive, Bitter Orange, Myrtle).
- **Heritage Atlas (أطلس نَفَس — حكاية أرض)**: Editorial exploration of Mesopotamian ecology, agricultural heritage, and historical waterways.
- **Plant Clinic (صيدلية نَفَس النباتية)**: Non-toxic symptom triage, diagnostic recommendations, and clearly labeled preliminary guidance.
- **Trilingual Accessibility**: Complete support for Iraqi Arabic (`ar-IQ`, RTL), Kurdish Sorani (`ckb`, RTL), and English (`en`, LTR).

## 🚀 Quick Start

### Prerequisites
- Node.js 18.x or 20+ (tested on Node 22)
- npm or pnpm

### Installation & Run
```bash
# Navigate to project directory
cd nafas

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to explore NAFAS.
